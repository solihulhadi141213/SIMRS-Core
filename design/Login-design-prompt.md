Ubah tampilan halaman login `_Page\Login\login.php` dengan ketentuan sebagai berikut :
1. Tampilan Dekstop
  - Desain halaman tampilan pada dekstop harus sesuai dengan `design\Login-Page.png`
  - Text menggunakan font 'open sans'
  - Terdiri dari 2 bagian kiri dan kanan.
  - Bagian kiri menggunakan background berwarna #1A5A6A
  - Bagian kanan adalah form, menggunakan background berwarna #DEEDF1 
  - Setiap form menggunakan garis pinggir berwarna #1A5A6A sebesar 2px
  - Logo menggunakan file image `assets\img\ui\app-logo.png`
2. Tampilan Mobile
  - Desain halaman tampilan pada mobile harus sesuai dengan `design\mobile.png`
  - Text menggunakan font 'open sans'
  - menggunakan background berwarna #DEEDF1 
  - Logo menggunakan file image `assets\img\ui\app-logo.png`
